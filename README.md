# Linear for Arch Linux

A lightweight Linux desktop launcher for [Linear](https://linear.app), built for Arch Linux.

It opens Linear in a dedicated Chromium app window while using your normal browser profile. That keeps Google, email, and SAML sign-in reliable—without the WebKit OAuth crashes common to unofficial wrappers.

## Install

```sh
makepkg -si
```

Then launch `linear-linux` or select **Linear** from the app launcher.

This package is independent from, and not endorsed by, Linear.
